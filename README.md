## 产品概述

清影是一套面向电商直播回放、长口播素材和批量二剪业务的 Windows 桌面软件。同一目标词在数小时长视频中可能出现几十次甚至数百次，一段视频又往往需要处理多个目标词，最终待处理位置可能达到数百乃至上千处。传统流程需要剪辑人员逐段搜索文稿、定位时间点、试听上下文并手工静音，处理时长会随视频长度和目标词数量快速增加。

清影将这项重复工作固化为可执行的软件流程：导入视频后自动生成带时间信息的中文文稿，搜索目标词即可集中查看候选位置；确认后的命中加入处理计划，经边界检查和正常语音保护后批量静音，并导出可继续进入剪映等专业软件复查的视频。

产品当前已经形成桌面客户端、端侧智能处理组件、授权服务、运营后台和 Windows 安装包发布链路。它不是通用视频编辑器，而是位于剪映等专业剪辑软件之前的**长视频口播目标词预处理软件**。

## 它解决什么问题

| 人工流程中的问题 | 清影的处理方式 |
| --- | --- |
| 长视频文稿难以快速检索 | 本地语音识别生成可搜索、带时间信息的文稿 |
| 同一目标词散落在大量时间点 | 汇总候选命中，并支持逐个跳转与一键加入处理 |
| 只看文字难以判断是否应处理 | 同屏提供文稿高亮、视频预览和时间轴定位 |
| 批量处理容易误伤正常语音 | 在导出前后执行候选复核、边界检查与正常音频保护 |
| 手工导出链路耗时且容易出错 | 使用 FFmpeg 处理音频并校验导出文件的可播放性与时长 |

## 核心工作流

1. **导入视频**：检查视频、音频轨和时间轴，准备端侧处理任务。
2. **识别文稿**：在用户设备内完成长音频识别，生成带时间信息的中文文稿。
3. **搜索目标词**：检索目标词及候选命中，集中查看它们在全文中的位置。
4. **可视化复核**：通过文稿高亮、视频预览、倍速播放和时间轴确认上下文。
5. **生成处理计划**：将确认后的候选位置加入计划；按需开启时间表达式处理。
6. **安全处理与导出**：批量处理目标词对应音频区间，保护正常语音，并输出可复查的视频。
7. **剪辑软件复查**：将结果导入剪映等工具，对重点位置进行最终人工确认。

## 产品能力

- **中文长视频识别**：面向长口播素材生成可检索文稿与时间信息。
- **目标词批量定位**：汇总同一目标词的多处候选，减少逐段查找和试听。
- **三位一体复核**：把文稿、视频预览和命中时间轴放在同一工作台中。
- **可控的处理计划**：目标词按组管理，可查看每个词对应的已选位置并随时撤回。
- **时间表达式处理**：可选处理具体时间、早中晚和特定节日等时间说法。
- **正常音频保护**：通过多阶段候选复核和边界检查，降低对正常语音的误处理风险。
- **本地优先**：视频、音频、识别文稿、处理计划和导出文件默认留在用户电脑中。
- **持续交付能力**：包含账号授权、设备与额度管理、任务进度、缓存清理、公告和客户端更新。

## 实际运行样例

在 RTX 3060 实际处理样例中，一段约 1 小时的中文口播视频包含 8 类目标词、319 个待处理位置，从识别结果进入批量处理到完成导出约需 10 分钟；导出结果经剪映文稿复查，该样例未发现目标词遗漏。

> 以上是单次真实样例记录，不构成通用性能或准确率承诺。实际耗时和结果受显卡、素材编码、语速、背景噪声、目标词数量与模型状态影响，最终成片仍需人工复查。

## 生产化与交付

清影并非单独的算法脚本或界面原型，而是一套可安装、可授权、可运营和可持续更新的软件系统：

- **桌面交付**：提供 Windows x64 安装包，客户端与端侧运行组件分开管理。
- **端侧运行时**：负责视频预检、音频提取、长音频识别、目标词处理、任务进度和缓存管理。
- **授权控制**：管理账号有效期、设备绑定、使用额度、重置次数和短时任务票据。
- **运营后台**：支持客户、套餐、合作方、订单、公告、协议、版本发布、风险事件和操作记录管理。
- **安全与审计**：具备后台多因素认证、登录限制、设备控制、关键操作审计、数据备份和服务健康检查。
- **版本发布**：支持版本检查、最低版本控制、安装包哈希校验、公告同步和升级引导。

## 系统架构

清影采用端云协同架构。视频、音频、识别文稿与导出文件只进入用户设备内的处理链路；云端服务负责账号、设备、额度、任务授权、公告和版本更新，不接收用户的视频、音频或识别文稿。

## 能力边界

- 清影专注于口播文稿识别、目标词搜索、目标词音频预处理和视频导出。
- 清影不提供人声分离、复杂剪辑、违规画面识别、马赛克、删除片段或逐帧修复。
- ASR、同拼音候选和字符级时间戳可能受到语速、口音、噪声和背景音乐影响。
- 处理结果不承诺百分之百无遗漏或无误伤，导出后应在专业剪辑软件中复查。
- 用户应确保素材来源与最终发布内容符合版权、肖像权、商标和平台规则。
